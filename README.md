# Centralized File Search System Analysis

## Project Overview

This project is a systems analysis of a real-world file-retrieval problem observed in a workplace environment. Employer-specific information and proprietary details have been anonymized.

The existing file environment relies on heavily nested folders and unintuitive naming conventions. Employees who do not already know where necessary files are stored may have difficulty locating them without assistance from experienced coworkers, creating dependence on institutional or tribal knowledge.

The proposed solution is a centralized search capability that allows users to locate authorized files across multiple existing repositories without requiring a full repository migration.

## Problem

The current environment creates several operational issues:

- Dependence on employee knowledge of file locations
- Ineffective searchability
- Excessive time spent locating files
- Interruptions to employees who know the file structure
- Risk of institutional knowledge loss when experienced employees leave

## Proposed Solution

The proposed system uses a centralized search interface supported by an indexing service and search index.

The solution would:

- Search across multiple existing repositories
- Index file names, file contents, and relevant metadata
- Allow users to search using ordinary keywords
- Preserve existing access permissions
- Support improved naming conventions and metadata
- Update the search index as files are added, modified, moved, or removed
